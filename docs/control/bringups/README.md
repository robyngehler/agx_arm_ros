# Bringups

This directory is the operational bringup surface.

## Use these docs by intent

- `launches.md`: which stable launch entrypoint or runtime slice to start
- `teach_and_run.md`: how to teach, capture, replay, and calibrate on top of the running control stack

## Scope rule

- `docs/control/bringups/` tells you how to run the system
- `docs/assets/control/` keeps analytical references and postmortem reasoning that should not become
  a second operational runbook
