# Asset And Runtime Docs

Stable component facts, validation state, and runtime integration notes.

## Canonical docs

- `repository_asset_inventory.md`: current repo-owned asset inventory
- `nero_asset_validation.md`: validated Nero description and asset state
- `omnihand_asset_validation.md`: validated OmniHand asset and integration state
- `control/`: control-chain and runtime behavior notes
- `mit_controller/`: MIT controller-specific inventories
- `omnihand/`: OmniHand integration options, bringup notes, SDK baseline, and active-joint mapping
- `tcp_offset/`: TCP offset documentation

## Scope

Keep stable factual inventories and component/runtime notes here. Historical or superseded document-level records should stay in `../development/`, not in `assets/`.
